# Multi Coding-Harness Compare 1.2.1

Released 2026-11-13. A security update: the `mcp` Python SDK moves from 1.26.0 to 1.30.0, the latest 1.x release.
Nothing else changes in how the app behaves.

## Security fixes

`mcp` 1.26.0 is affected by seven published advisories. Version 1.30.0 fixes all of them.

| Advisory | Severity | Fixed in | Summary |
|---|---|---|---|
| [GHSA-hvrp-rf83-w775](https://github.com/advisories/GHSA-hvrp-rf83-w775) | High | 1.27.2 | Experimental task handlers let any client access and cancel other clients' tasks. |
| [GHSA-jpw9-pfvf-9f58](https://github.com/advisories/GHSA-jpw9-pfvf-9f58) | High | 1.27.2 | HTTP transports served session requests without verifying the authenticated principal. |
| [GHSA-vj7q-gjh5-988w](https://github.com/advisories/GHSA-vj7q-gjh5-988w) | High | 1.28.1 | The WebSocket server transport did not support Host/Origin validation. |
| [GHSA-5h93-6whr-6q8j](https://github.com/advisories/GHSA-5h93-6whr-6q8j) | Moderate | 1.30.0 | HTTP client transports followed cross-origin redirects carrying custom headers. |
| [GHSA-84m7-p3x7-pcfv](https://github.com/advisories/GHSA-84m7-p3x7-pcfv) | Moderate | 1.30.0 | Unbounded session accumulation in the StreamableHTTP transport allowed resource exhaustion. |
| [GHSA-rwrf-2pqf-9j8j](https://github.com/advisories/GHSA-rwrf-2pqf-9j8j) | Moderate | 1.30.0 | The client fetched server-chosen `$ref` URLs while validating tool results. |
| [GHSA-w4fh-qvv9-3v23](https://github.com/advisories/GHSA-w4fh-qvv9-3v23) | Moderate | 1.30.0 | Server bearer-token authentication accepted tokens issued for a different resource. |

## What changed

| File | Change |
|---|---|
| `pyproject.toml` | `mcp==1.26.0` → `mcp==1.30.0` |
| `requirements.lock` | The same pin. Every other locked version is unchanged; the lock still resolves with all other pins fixed. |
| `harness_image/versions.py` | `MCP_VERSION` → `1.30.0`, the version vendored into the AgentCore runtime bundles. |
| `README.md` | The bundled `mcp` version. |
| Version | 1.2.0 → 1.2.1 in `pyproject.toml` and the four places the app reports it. |

1.30.0 is the newest 1.x release. The 2.x line is a separate major version with breaking changes and is not adopted
here.

## Upgrading

1. Stop the services, pull, and re-run `./bootstrap.sh`. Its install stage reinstalls the workstation dependencies
   from `requirements.lock`, so the local app picks up `mcp` 1.30.0.
2. **AgentCore:** the runtimes keep the `mcp` version they were deployed with. To move them to 1.30.0, redeploy them
   with `./bootstrap.sh --deploy`. This changes AWS resources, so run it deliberately.

No configuration changes are needed.

## Verification

- The full suite passes: 1750 Python tests and all 11 UI test files.
- `uv pip check` reports every installed package compatible.
